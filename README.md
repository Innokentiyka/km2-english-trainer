# Тренажёр технического английского КМ-2

Статический сайт для подготовки по вариантам I–VI: 180 карточек лексики, 60 предложений для перевода и 30 грамматических заданий с объяснениями.

## Возможности

- Выбор варианта или всех вариантов сразу.
- Карточки лексики с самостоятельной оценкой знания.
- Грамматика с пояснениями и контрольная без подсказок.
- Перевод с образцом и самопроверкой смысла.
- Повторение ошибок и сохранение прогресса в localStorage браузера.
- Адаптивный интерфейс для компьютера и телефона.

## Запуск

Откройте index.html в браузере. Сборка и установка зависимостей не требуются.

## GitHub Pages

1. Откройте Settings → Pages репозитория.
2. Выберите Deploy from a branch.
3. Укажите ветку main и каталог / (root), затем Save.
4. Дождитесь завершения публикации и используйте адрес, указанный GitHub.

Доступность Pages для приватного репозитория зависит от плана GitHub. Если настройка недоступна, можно самостоятельно сделать репозиторий публичным либо выбрать другой статический хостинг. Публикация Pages не включена автоматически.

## Файлы

- index.html — страница сайта.
- style.css — оформление.
- app.js — логика тренажёра.
- data.js — задания, переводы, ответы и пояснения.
- .nojekyll — отключение обработки Jekyll.

## Учебный материал

Л.С. Бирюкова, Ж.В. Демьянова, Н.А. Копылова, М.А. Слепнева. «Технический английский. Базовый курс». МЭИ, 2023, Units 4–6. Номера опорных страниц приведены в разборе заданий.

Ответы составлены для подготовки, а не являются официальным ключом. Неоднозначные задания и исправленные опечатки отмечены в объяснениях. Свободный перевод и карточки оцениваются самим обучающимся.

Прогресс хранится только в текущем браузере и не синхронизируется между устройствами. Исходные PDF учебника не включены.
